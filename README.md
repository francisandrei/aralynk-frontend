# Aralynk Front-End Demo

A responsive front-end concept for Aralynk, a proposed local job-matching platform for BASC students and businesses in San Ildefonso, Bulacan.

## Built with
- HTML
- CSS
- Vanilla JavaScript

## Run locally
1. Download or extract this folder.
2. Open `index.html` in your browser.
3. Try the job search, work-type filter, navigation menu, and sample job details.

## Current demo features
- Responsive landing page
- Sample job cards
- Search by role, skill, or business
- Filter by work type
- Demo dialogs for login, getting started, and viewing job details
- Mobile navigation

## Important limitation
This is front-end only. It does not have a real database, account registration, login, job applications, notifications, or employer messaging. The displayed jobs are sample listings and are not confirmed vacancies.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `aralynk-frontend`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish your site. The Pages URL will appear in that settings section.
